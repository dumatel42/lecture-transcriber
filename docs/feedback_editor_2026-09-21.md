### 2. Замечания по оформлению текста (это новые требования)
1. **Сокращения разворачивать.** В тексте, предназначенном для чтения, нельзя оставлять
   сокращённые формы — *I'm, you're, you've* должны быть *I am, you are, you have*.
   Не знает, может ли это делать ИИ. Исключение — редкие случаи внутри прямой речи
   (в кавычках), и там это, скорее, работа редактора.
2. **Курсив для санскрита — везде.** Не все санскритские термины оказались курсивом.
   Нужно: все санскритские термины курсивом, и **названия книг** внутри текста тоже
   курсивом.
3. **Шлока с источником — прямым шрифтом.** Когда даётся шлока вместе с указанием
   источника, там, разумеется, курсива быть не должно (прямое начертание).
4. **Диакритика:** слово *Vedānta* не всегда с долгой *ā* — нужно проверить написание.
